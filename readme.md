# Receptsökaren - första uppgiften med API

Detta var den första laborationen som behandlade APIer i kursen. I övrigt var laborationens upplägg väldigt likt laboration 5 vilket jag verkligen uppskattade. Enligt instruktion skulle endast det första receptet i sökresultatet visas.

## Reflektioner

Jag har egentligen inte så mycket tankar och reflektioner från denna labb mer än att poletten verkligen trillade ned gällande framförallt DOM. Det var nu med facit i hand väldigt nyttigt att få den färdiga strukturen med funktioner och kommentarer i laboration 5. På så sätt hade man ett hum redan från början om hur man skulle strukturera allt nu i denna labb när man inte hade någon hjälp. Jag tycker att just detta arbete med APIer öppnar för så många nya möjligheter och tankar inför projektuppgiften. Javascript känns mer och mer intressant desto mer jag lär mig!
